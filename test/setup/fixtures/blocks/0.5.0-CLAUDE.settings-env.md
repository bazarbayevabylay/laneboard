This project tracks work with laneboard (task board & CLI for AI coding agents). Its store is /home/dev/project/.laneboard (LANEBOARD_DIR is set for this project in .claude/settings.json).
MANDATORY for every request, even when nobody mentions tasks and the board is empty: before your first file change, run `laneboard prime` and claim your task or create one (prime prints the command); comment each meaningful step; when done: commit, then `laneboard finish <ID> --result "<result>" --json` (one write: the result, the commit link, the status). No untracked work.
Without `--as` your writes use this session's default name (`laneboard prime` shows it); subagents and parallel workers of one session pass their own `--as <name>`.
